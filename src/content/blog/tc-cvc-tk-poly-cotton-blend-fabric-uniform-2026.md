**ผ้า TC, CVC, TK** คือสามชื่อผ้าผสมโพลีเอสเตอร์-คอตตอนที่เจอบ่อยที่สุดเวลาสั่งผลิตเสื้อยูนิฟอร์มและเสื้อโปรโมชัน สรุปสั้น ๆ ก่อนเลย: **TC = โพลีเอสเตอร์ 65 คอตตอน 35** (โพลีเป็นส่วนใหญ่), **CVC = คอตตอนเป็นส่วนใหญ่** (ราว 60/40 หรือ 55/45) และ **TK ในตลาดผ้าไทย = โพลีเอสเตอร์ล้วน 100%** ทั้งสามตัวถูกเลือกมาแทนคอตตอน 100% เพราะหดน้อย ยับยาก ทนซักหนัก และต้นทุนคุมได้ บทความนี้ถอดรหัสชื่อ เทียบสมบัติกับคอตตอนแบบตรงไปตรงมา และช่วยคุณเลือกให้ตรงงาน

## TC, CVC, TK ย่อมาจากอะไร แต่ละตัวผสมกี่เปอร์เซ็นต์

ชื่อเรียกพวกนี้ฟังดูงง แต่พอรู้ที่มาจะจำง่ายทันที

| ชื่อผ้า | ย่อมาจาก | อัตราส่วน (โดยประมาณ) | ใครเป็นส่วนใหญ่ |
| :--- | :--- | :--- | :--- |
| **TC** | Tetoron Cotton | โพลีเอสเตอร์ 65% / คอตตอน 35% | โพลีเอสเตอร์ |
| **CVC** | Chief Value Cotton | คอตตอน 60% / โพลีเอสเตอร์ 40% (หรือ 55/45) | คอตตอน |
| **TK** | (ศัพท์ตลาดไทย) | โพลีเอสเตอร์ 100% | โพลีเอสเตอร์ล้วน |

- **TC** — "Tetoron" เป็นชื่อทางการค้าเก่าของเส้นใยโพลีเอสเตอร์จากญี่ปุ่น (Toray/Teijin) พอเอามาผสมคอตตอนจึงเรียกย่อว่า T/C อัตราส่วนมาตรฐานที่ตลาดใช้กันคือ 65/35
- **CVC** — ย่อจาก *Chief Value Cotton* มาจากระบบพิกัดศุลกากรที่เรียกชื่อผ้าตามเส้นใยที่มี "มูลค่า/สัดส่วนมากที่สุด" เมื่อคอตตอนเป็นส่วนใหญ่จึงเรียก Chief Value Cotton ค่าที่พบบ่อยคือ 60/40 หรือ 55/45 (บางแหล่งถึง 80/20)
- **TK** — เป็นศัพท์เฉพาะตลาดผ้าไทย หมายถึงผ้าถักโพลีเอสเตอร์ล้วน 100% ยืนยันโดยผู้ผลิตผ้าถักรายใหญ่ของไทยอย่าง Jongstit นิยมทำเสื้อโปโล ยูนิฟอร์มพนักงาน และชุดกีฬา เพราะรับงานสกรีนและซับลิเมชันได้สีสดทน

> อยากเข้าใจว่าคอตตอนเองก็มีหลายเกรด อ่านต่อที่ [ผ้าคอตตอนมีกี่เกรด ทำไมเป็นเนื้อผ้าอันดับ 1 ของเสื้อยืด](/blog/cotton-fabric-grades-explained)

## ผ้าผสมเทียบคอตตอน 100% ต่างกันตรงไหนบ้าง

หัวใจของเรื่องนี้คือ "การแลกกัน" (trade-off) ระหว่างความสบายของคอตตอนกับความทนทาน-ดูแลง่ายของโพลีเอสเตอร์ ยิ่งมีโพลีมาก ยิ่งได้ความทน แต่เสียความระบายอากาศ

### ระบายอากาศและซับเหงื่อ — คอตตอนชนะ

ตัวเลขที่อธิบายทุกอย่างในบรรทัดเดียวคือ **ค่าการคืนความชื้น (moisture regain)** ตามตาราง ASTM D1909: **คอตตอน = 8.5% ส่วนโพลีเอสเตอร์ = เพียง 0.4%** แปลว่าคอตตอนดูดซับน้ำ/เหงื่อได้ดีและระบายอากาศ ส่วนโพลีเอสเตอร์แทบไม่ดูดน้ำ จึงแห้งไวและรีดผ้าให้เหงื่อระเหยออกผิวได้ แต่ถ้าอากาศร้อนจัดอาจรู้สึกเหนียวตัว ดังนั้นยิ่งผ้ามีคอตตอนมาก (CVC > TC > TK) ยิ่งใส่สบายในเมืองร้อน

### หดตัวและอยู่ทรง — ผ้าผสมชนะ

- คอตตอนถัก(jersey) ล้วนหดมากที่สุด ราว 3–7% ถ้าไม่ผ่านการอบกันหด
- คอตตอนที่ผ่าน Sanforized/pre-shrunk เหลือหดต่ำกว่า ~2%
- โพลีเอสเตอร์หดแทบเป็นศูนย์ (<1%) ผ้าผสม 65/35 จึงมักหดต่ำกว่า ~2–2.5%

เสื้อยูนิฟอร์มที่ต้องคงไซส์หลังซักหลายสิบครั้ง ผ้าผสมจึงได้เปรียบชัด

### ยับ สีตก ความทน — ผ้าผสมได้เปรียบ

โพลีเอสเตอร์มีความแข็งแรงและทนการเสียดสีสูงกว่าคอตตอน และ **คงความแข็งแรงไว้แม้ตอนเปียก** ผ้าผสมจึงทนซักอุตสาหกรรมได้ดี ยับยากกว่า และเก็บสีได้ดีกว่า (สีไม่ค่อยซีด) มีงานวิจัยเชิงวิชาการ (Marsha & Chowdhary, 2018) เปรียบเทียบเสื้อคอตตอนกับเสื้อผสมคอตตอน/โพลีเอสเตอร์ พบว่าเสื้อผ้าผสมมีค่าการระบายอากาศและความทนแรงดันแตก (bursting strength) สูงกว่าเสื้อคอตตอนล้วนในสภาพก่อนซัก

### ข้อที่คอตตอนกลับมาชนะ — เรื่องขุย (pilling)

หลายคนเข้าใจผิดว่าผ้าผสมทนกว่าเลยไม่เป็นขุย ความจริงตรงข้าม: เส้นใยโพลีเอสเตอร์เหนียวมากจนขุยที่เกิดขึ้น **ไม่หลุด** แต่พันกันเป็นเม็ดเกาะผิวผ้า ผ้าผสม/โพลีจึงมีแนวโน้มเป็นขุยง่ายกว่าคอตตอน 100% ที่มักบางลงหรือซีดแทน ตรงนี้เป็นจุดที่ต้องบอกลูกค้าตามจริง

| สมบัติ | ผ้าผสม (TC/CVC/TK) | คอตตอน 100% |
| :--- | :--- | :--- |
| ระบายอากาศ/ซับเหงื่อ | ด้อยกว่า (ยิ่งโพลีมากยิ่งด้อย) | **ดีกว่า** |
| หดตัว | **น้อยกว่า** | มากกว่า (ถ้าไม่อบกันหด) |
| ยับ | **ยับยาก** | ยับง่าย |
| สีตก/ซีด | **เก็บสีดีกว่า** | ซีดง่ายกว่า |
| ความทน/อยู่ทรง | **ทนกว่า** | ด้อยกว่า |
| เป็นขุย (pilling) | เป็นง่ายกว่า | **เป็นยากกว่า** |
| ต้นทุน | **ถูกกว่า** | สูงกว่า (เกรดดี) |

## แล้วงานแบบไหนควรใช้ตัวไหน

1. **ยูนิฟอร์มบริษัท ร้านอาหาร-คาเฟ่ ที่ซักหนักทุกวัน** → TC หรือ CVC เพราะไม่หด รีดง่าย ดูเรียบร้อยเสมอ ต้นทุนคุมได้ ถ้าอยากให้พนักงานใส่สบายขึ้นในครัวร้อน ๆ ให้ขยับไป CVC ที่คอตตอนเยอะกว่า
2. **เสื้อโปโล/เสื้อกีฬา งานสกรีนหรือซับลิเมชันสีจัด** → TK (โพลีล้วน) รับสีสดและทนซัก เหมาะกับงานพิมพ์ลายเต็มตัว
3. **เสื้อโปรโมชัน แจกงานอีเวนต์ จำนวนมาก งบจำกัด** → TC คุ้มสุด ราคาประหยัด ลายพิมพ์ทนพอสมควร
4. **เสื้อยืดแบรนด์ที่ขายความพรีเมียม ใส่ลำลอง เน้นสัมผัส** → คอตตอน 100% (หรือ CVC ถ้าต้องการลดหด) ยังได้เปรียบเรื่องความนุ่มและระบายอากาศ

## ดูแลรักษาผ้าผสมให้ใช้ได้นาน

เพราะมีโพลีเอสเตอร์ที่ไวต่อความร้อน วิธีซัก-รีดจึงต่างจากคอตตอนล้วนเล็กน้อย

- ซักน้ำเย็นถึงอุ่น ~30–40°C (ใช้ 60°C เฉพาะคราบหนักบนผ้าทน ๆ)
- ใช้ผงซักฟอกอ่อน **เลี่ยงน้ำยาฟอกขาวและน้ำยาปรับผ้านุ่ม**
- อบแห้งไฟอ่อนหรือผึ่งลม **เลี่ยงความร้อนสูง** เพราะโพลีอาจเงาวับหรือละลาย
- รีดไฟอ่อนถึงกลาง โดยรวมผ้าผสมรีดง่ายกว่าคอตตอนล้วนอยู่แล้ว

เรื่องน้ำหนักผ้า (GSM) ใช้เกณฑ์เดียวกับเสื้อยืดทั่วไป: บาง ~120–150, กลาง ~150–180, หนา 180+ GSM อ่านวิธีเลือกความหนาให้ตรงทรงที่ [เสื้อยืด Heavyweight กี่ GSM ดี เลือกผ้าหนาให้ตรงสไตล์](/blog/heavyweight-tshirt-gsm-oversized-boxy-2026)

## สรุป

ผ้า TC, CVC, TK ไม่ใช่เรื่องลึกลับ ถ้าจำหลักง่าย ๆ ว่า **TC = โพลีเยอะ (65/35), CVC = คอตตอนเยอะ (ราว 60/40), TK = โพลีล้วน 100%** จากนั้นเลือกตามงาน: ซักหนัก-คุมต้นทุน-อยู่ทรงไปทางผ้าผสม, เน้นสบาย-ระบายอากาศ-พรีเมียมไปทางคอตตอน สิ่งที่ต้องบอกลูกค้าตามตรงคือผ้าผสมแลกความทนมาด้วยการระบายอากาศที่ด้อยลงและโอกาสเป็นขุยที่มากขึ้น
