**เสื้อ Hi-Vis สะท้อนแสง** ที่ได้มาตรฐานต้องมีสององค์ประกอบครบเสมอ คือผ้าสีเรืองแสงที่เด่นตอนกลางวัน และแถบสะท้อนแสงที่สะท้อนไฟรถกลับหาคนขับตอนกลางคืน มาตรฐานสากลที่ใช้อ้างอิงมากที่สุดคือ EN ISO 20471 ซึ่งแบ่งระดับการมองเห็นเป็น 3 คลาสตามพื้นที่วัสดุ บทความนี้อธิบายว่าแต่ละคลาสต่างกันตรงไหน เลือกยูนิฟอร์มเซฟตี้ให้ตรงงานอย่างไร และดูแลรักษาแบบไหนไม่ให้แถบสะท้อนแสงเสื่อมก่อนเวลา เหมาะกับธุรกิจก่อสร้าง โลจิสติกส์ งานริมถนน และทีมส่งของ

## Hi-Vis ทำงานยังไง: เรืองแสง vs สะท้อนแสง

หลายคนเข้าใจผิดว่าเสื้อสะท้อนแสงคือเสื้อที่ "เรืองแสงเอง" ความจริงมันคือสองเทคโนโลยีคนละแบบที่ต้องทำงานร่วมกัน

- **ผ้าสีเรืองแสง (Fluorescent)** — ดูดแสงยูวี/แสงคลื่นสั้นแล้วปล่อยกลับออกมาเป็นแสงสีสว่างกว่าเดิม (เหลืองอมเขียว) ทำให้เด่นตอนกลางวัน เช้ามืด และพลบค่ำ แต่ **ไม่ทำงานตอนกลางคืน** เพราะไฟรถและไฟถนนแทบไม่มีรังสียูวี
- **แถบสะท้อนแสง (Retroreflective)** — ภายในมีเม็ดแก้วจิ๋วหรือปริซึมขนาดเล็กที่สะท้อนแสง เช่น ไฟหน้ารถ ให้ย้อนกลับตรงไปหาต้นกำเนิดแสง นี่คือกลไกที่ทำให้คนขับเห็นคนใส่ตอนกลางคืน

สีเรืองแสงที่มาตรฐาน EN ISO 20471 อนุญาตมี 3 สีคือ เหลืองเรืองแสง ส้มแดงเรืองแสง และแดงเรืองแสง ∴ เสื้อที่พื้นเป็นสีทึบธรรมดาแล้วติดแค่แถบสะท้อนแสงบาง ๆ จะไม่ผ่านมาตรฐาน Hi-Vis เต็มรูปแบบ

## 3 คลาสของ EN ISO 20471 ต่างกันที่ "พื้นที่วัสดุ"

มาตรฐาน EN ISO 20471:2013 (ชื่อเต็ม *High visibility clothing — Test methods and requirements*) จัดระดับการมองเห็นเป็น 3 คลาส ยิ่งคลาสสูง ยิ่งต้องมีพื้นที่ผ้าเรืองแสงและแถบสะท้อนแสงมากขึ้น

| คลาส | ผ้าเรืองแสงขั้นต่ำ | แถบสะท้อนแสงขั้นต่ำ | เหมาะกับ |
| :--- | :--- | :--- | :--- |
| Class 1 | 0.14 ตร.ม. | 0.10 ตร.ม. | งานเสี่ยงต่ำ จราจรช้า |
| Class 2 | 0.50 ตร.ม. | 0.13 ตร.ม. | ความเสี่ยงปานกลาง |
| Class 3 | 0.80 ตร.ม. | 0.20 ตร.ม. | ริมถนนความเร็วสูง/ทางหลวง |

จุดสำคัญคือ **Class 3 มักทำเป็นเสื้อกั๊กตัวเดียวไม่ได้** เพราะต้องมีพื้นที่มากพอจนต้องคลุมทั้งท่อนบนและขา เช่น เสื้อแจ็กเก็ตแขนยาวคู่กับกางเกง หรือชุดหมี ส่วนแนวทางที่ผู้ขายนิยมอ้างอิง (ไม่ใช่ข้อความในตัวมาตรฐานโดยตรง) มักผูกคลาสกับความเร็วจราจร เช่น งานจราจรช้าใช้ Class 1 และงานความเร็วสูงใช้ Class 3

> เสื้อ Hi-Vis จัดเป็น PPE ที่ต้องผ่านการตรวจรับรอง โดยใบรับรองมักมีอายุ 5 ปีและต้องต่ออายุ เมื่อสั่งผลิตควรขอดูหลักฐานการทดสอบวัสดุประกอบด้วย

## EN ISO 20471 กับ ANSI/ISEA 107 ต่างกันอย่างไร

ถ้าลูกค้าหรือคู่ค้าเป็นบริษัทสหรัฐฯ จะเจออีกมาตรฐานคือ ANSI/ISEA 107 ซึ่งเป้าหมายเดียวกันแต่ระบบจัดกลุ่มต่างกัน

- **EN ISO 20471** — มาตรฐานสากล/ยุโรป (เครื่องหมาย CE) วัดพื้นที่เป็นตารางเมตร
- **ANSI/ISEA 107** — มาตรฐานสหรัฐฯ วัดพื้นที่เป็นตารางนิ้ว และแบ่งเป็น "Type" คือ Type O (นอกถนน), Type R (ริมถนน) และ Type P (งานกู้ภัย/ความปลอดภัยสาธารณะ)

ค่าที่ยืนยันตรงกันหลายแหล่งของ ANSI คือ แถบสะท้อนแสงขั้นต่ำ Class 2 = 201 ตร.นิ้ว และ Class 3 = 310 ตร.นิ้ว สรุปคือถ้าจะส่งออกหรือขายให้บริษัทข้ามชาติ ต้อง **ระบุให้ชัดว่าอิงมาตรฐานไหน** เพราะเสื้อที่ผ่าน EN ISO 20471 ไม่ได้แปลว่าผ่าน ANSI โดยอัตโนมัติ

### แล้วเมืองไทยใช้มาตรฐานอะไร

เท่าที่ตรวจสอบ ยังไม่พบเลขมาตรฐาน มอก. เฉพาะสำหรับเสื้อ Hi-Vis สะท้อนแสงโดยตรง ในทางปฏิบัติผู้ผลิตและผู้ซื้อในไทยจึงมักอ้างอิงมาตรฐานสากล EN ISO 20471 หรือ ANSI/ISEA 107 แทน ดังนั้นเวลาสั่งผลิตควรระบุมาตรฐานสากลที่ต้องการ พร้อมคลาสและสีที่ต้องใช้ลงในสเปก จะได้ของตรงงานและตรวจรับได้

## เลือกยูนิฟอร์มเซฟตี้ให้ตรงงาน

เสื้อ Hi-Vis ไม่ได้มีแค่เรื่องแถบสะท้อนแสง แต่รวมถึงเนื้อผ้าที่ต้องใส่ทำงานกลางแดดร้อนได้ทั้งวัน

1. **เลือกคลาสตามความเสี่ยงจริง** — อย่าจ่ายเกินจำเป็นถ้างานอยู่ในลานปิด แต่ก็อย่าประหยัดจนต่ำกว่าความเสี่ยงริมถนน
2. **เลือกผ้าให้ระบายเหงื่อ** — งานกลางแจ้งเมืองร้อนควรใช้ผ้าที่ระบายอากาศและซับเหงื่อดี ดูแนวทางเลือกผ้าได้ที่ [ผ้าระบายเหงื่อกันยูวี เลือกเนื้อผ้ายูนิฟอร์ม-เสื้อกีฬา](/blog/moisture-wicking-uv-fabric-uniform-sport-heat)
3. **วางตำแหน่งโลโก้ให้ไม่บังพื้นที่สะท้อนแสง** — งานสกรีนหรือปักโลโก้บริษัทต้องไม่ไปลดพื้นที่วัสดุจนหลุดคลาส
4. **คิดเรื่องทรงและไซซ์รวม** — ถ้าทำเป็นโปโลเซฟตี้สำหรับหัวหน้างาน ดูแนวเลือกผ้าโปโลได้ที่ [สั่งทำเสื้อโปโลยูนิฟอร์มบริษัท เลือกเนื้อผ้าแบบไหนดี](/blog/company-polo-uniform-fabric-guide)

## ดูแลอย่างไรไม่ให้แถบสะท้อนแสงตาย

เสื้อ Hi-Vis จะมีตัวเลข "จำนวนครั้งซักสูงสุด" พิมพ์บนป้าย (ค่าที่พบบ่อยคือราว 25 ครั้ง แต่บางรุ่นสูงกว่านั้น ให้ยึดตามที่ระบุ) เมื่อเกินจำนวนนี้ ประสิทธิภาพการมองเห็นอาจไม่ผ่านมาตรฐานแล้ว วิธีถนอมให้ใช้ได้นาน

**ควรทำ**

- ซักน้ำเย็นหรืออุ่น อุณหภูมิไม่เกินราว 40°C โปรแกรมถนอมผ้า
- กลับตะเข็บในออกก่อนซัก ใช้น้ำยาซักอ่อน ๆ ค่า pH เป็นกลาง
- ผึ่งลมให้แห้ง เลี่ยงความร้อนสูงที่ทำให้กาวแถบสะท้อนแสงแตก

**ควรเลี่ยง**

- น้ำยาฟอกขาว — ทำลายสีเรืองแสงและเนื้อวัสดุ
- น้ำยาปรับผ้านุ่ม — สารเคลือบจะไปหุ้มเม็ดแก้วบนแถบสะท้อนแสงจนสะท้อนไฟไม่ได้
- อบแห้งความร้อนสูงและรีดทับแถบสะท้อนแสงโดยตรง

## สรุป

เสื้อ Hi-Vis สะท้อนแสงที่ดีต้องครบทั้งผ้าเรืองแสงสำหรับกลางวันและแถบสะท้อนแสงสำหรับกลางคืน เลือกคลาสตามมาตรฐาน EN ISO 20471 (หรือ ANSI/ISEA 107 หากทำตลาดสหรัฐฯ) ให้ตรงความเสี่ยงจริง วางโลโก้โดยไม่ลดพื้นที่วัสดุ และดูแลการซักให้ถูกวิธีเพื่อไม่ให้แถบสะท้อนแสงเสื่อมก่อนเวลา เมื่อไม่มี มอก. เฉพาะทาง การระบุมาตรฐานสากลลงสเปกคือวิธีที่ปลอดภัยที่สุด

ต้องการสั่งผลิตยูนิฟอร์มเซฟตี้หรือเสื้อทีมงานติดแถบสะท้อนแสงพร้อมโลโก้บริษัท? ปรึกษาทีมงาน Thana Plus 153 เรื่อง[งานรับผลิตเสื้อและยูนิฟอร์มครบวงจร](/services) เราช่วยเลือกผ้า คลาส และตำแหน่งงานพิมพ์ให้ตรงมาตรฐานและงบประมาณ
