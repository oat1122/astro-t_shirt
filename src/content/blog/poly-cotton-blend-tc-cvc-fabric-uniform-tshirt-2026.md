**ผ้าผสมโพลีคอตตอน TC vs CVC** ต่างกันที่ "เส้นใยไหนเป็นพระเอก" พูดสั้น ๆ คือ TC มีโพลีเอสเตอร์เป็นหลัก (ยอดฮิตคือโพลี 65% ฝ้าย 35%) เน้นความทน รีดง่าย ราคาคุม ส่วน CVC (Chief Value Cotton) มีฝ้ายเป็นหลักเกินครึ่ง (เช่น ฝ้าย 60% โพลี 40%) เน้นสัมผัสนุ่มและใส่สบายกว่า การเลือกให้ถูกจึงขึ้นกับว่างานของคุณให้น้ำหนัก "ความทน" หรือ "ความนุ่ม" มากกว่ากัน บทความนี้เทียบให้ครบทั้งสัดส่วน คุณสมบัติ และการใช้งานจริง เพื่อให้สั่งผลิตได้ตรงงานตั้งแต่ล็อตแรก

## TC และ CVC ย่อมาจากอะไร

- **TC = Terylene/Cotton (หรือ T/C)** — ผ้าผสมที่ **โพลีเอสเตอร์เป็นเส้นใยหลัก** สัดส่วนที่พบบ่อยคือ 65/35, 80/20 และ 55/45 (โพลี/ฝ้าย)
- **CVC = Chief Value Cotton** — แปลตรงตัวว่า "ฝ้ายเป็นมูลค่าหลัก" หมายถึงผ้าผสมที่ **ฝ้ายมากกว่า 50%** สัดส่วนยอดนิยมคือ 60/40 และ 70/30 (ฝ้าย/โพลี)

> จุดที่คนสั่งผลิตพลาดบ่อย: ป้ายเขียน "65/35" เหมือนกัน แต่ TC 65/35 คือโพลี 65% ส่วน CVC 65/35 คือฝ้าย 65% — ถ้าไม่ระบุว่าเปอร์เซ็นต์แรกคือเส้นใยอะไร อาจได้ผ้าคนละสัมผัสไปเลย

## เทียบคุณสมบัติแบบเห็นภาพ

| คุณสมบัติ | TC (โพลีเป็นหลัก) | CVC (ฝ้ายเป็นหลัก) |
| --- | --- | --- |
| สัมผัส | เรียบลื่น แข็งกว่าเล็กน้อย | นุ่ม ใกล้ฝ้ายล้วน |
| ระบายอากาศ/ซับเหงื่อ | ปานกลาง | ดีกว่า |
| ความทน/คงรูป | ทนมาก ไม่ค่อยเสียทรง | ทนดี แต่รองจาก TC |
| ยับ/หด | ยับและหดน้อยมาก | ยับ/หดน้อยกว่าฝ้ายล้วน |
| รีดง่าย | ง่ายที่สุด | ง่าย |
| ต้นทุน | ถูกกว่า | สูงกว่าเล็กน้อย |
| ภาพลักษณ์ | เน้นใช้งาน | ดูพรีเมียมกว่า |

โดยสรุป โพลีเอสเตอร์ให้ "ความทน คงรูป กันยับ ราคาคุม" ส่วนฝ้ายให้ "ความนุ่ม ซับเหงื่อ ใส่สบาย" ผ้าผสมจึงคือการหาสมดุลระหว่างสองขั้วนี้ ยิ่งฝ้ายเยอะ (CVC) ยิ่งไปทางสบาย ยิ่งโพลีเยอะ (TC) ยิ่งไปทางทน

## เลือกยังไงให้เหมาะกับงาน

### เลือก TC เมื่อ
- ทำ **ยูนิฟอร์มพนักงานงานหนัก** เช่น โรงงาน ช่าง คลังสินค้า ที่ต้องซักบ่อยและทนยับ
- ต้องการเสื้อ **รีดเรียบง่าย คงทรง** ใส่ทั้งวันไม่ย้วย
- คุม **งบต่อตัว** สำหรับผลิตจำนวนมาก

### เลือก CVC เมื่อ
- ทำ **เสื้อโปโล/ยูนิฟอร์มออฟฟิศ คาเฟ่ ร้านอาหาร** ที่เน้นภาพลักษณ์และสัมผัสนุ่ม
- ทำ **เสื้อยืดแบรนด์** ที่อยากได้ฟีลใกล้ฝ้ายล้วนแต่ยังกันยับ/หดได้ดีกว่า
- ต้องการงานพิมพ์คมและสีติดดี (ฝ้ายเยอะช่วยเรื่องการซึมของหมึกสูตรน้ำ)

ถ้ากำลังเลือกเนื้อผ้าเสื้อโปโลบริษัทโดยเฉพาะ อ่านเจาะลึกเพิ่มได้ที่ [สั่งทำเสื้อโปโลยูนิฟอร์มบริษัท เลือกเนื้อผ้าแบบไหนดี](/blog/company-polo-uniform-fabric-guide) ซึ่งลงรายละเอียดโครงสร้างผ้าอย่าง Pique ประกอบ

## อย่าสับสนระหว่าง "สัดส่วนผสม" กับ "โครงสร้างถัก"

จุดที่มือใหม่งงบ่อยคือ TC/CVC บอกแค่ **สัดส่วนเส้นใย** (ฝ้ายกี่ % โพลีกี่ %) ไม่ได้บอก **โครงสร้างการถัก** ผ้าผสมโพลีคอตตอนก็ยังถักเป็น Single Jersey (เสื้อยืด), Pique (เสื้อโปโล) หรือ Interlock ได้ทั้งนั้น สองเรื่องนี้เลือกแยกกันคนละแกน

- สัดส่วนเส้นใย → กำหนดสัมผัส/ความทน/การซับเหงื่อ (TC vs CVC vs ฝ้ายล้วน)
- โครงสร้างถัก → กำหนดหน้าตาและการใช้งาน (ยืด/โปโล/หนา)

อยากเข้าใจโครงสร้างถักให้ลึกขึ้น อ่านต่อที่ [ผ้า Single Jersey, Pique, Interlock ต่างกันยังไง](/blog/knit-fabric-single-jersey-pique-interlock) และถ้าอยากรู้ว่าทำไมฝ้ายเป็นเส้นใยยอดนิยม ดูที่ [ผ้าคอตตอนมีกี่เกรด](/blog/cotton-fabric-grades-explained)

## เกร็ดก่อนสั่งผลิต

1. **ระบุสัดส่วนให้ชัด** — บอกเป็น "ฝ้าย X% โพลี Y%" ไปเลย ไม่ต้องพึ่งแค่คำว่า TC/CVC เพื่อกันเข้าใจผิด
2. **นึกถึงงานพิมพ์** — ถ้าจะสกรีนกัดสี (discharge) ต้องใช้ฝ้ายเยอะ ผ้าโพลีสูงอย่าง TC จะกัดสีไม่ออก ควรเลือก CVC หรือฝ้ายล้วน
3. **นึกถึงการซัก** — ผ้าโพลีสูงแห้งไว รีดง่าย เหมาะงานยูนิฟอร์มที่หมุนเวียนซักถี่
4. **ขอตัวอย่างผ้าจริง** — สัมผัสและน้ำหนัก (GSM) ต่างกันแม้สัดส่วนเท่ากัน ควรจับผ้าจริงก่อนล็อกออร์เดอร์

## สรุป

ผ้าผสมโพลีคอตตอน TC vs CVC เลือกไม่ยากถ้าจำหลักไว้ว่า **TC โพลีนำ = ทน รีดง่าย คุมงบ** เหมาะยูนิฟอร์มงานหนัก ส่วน **CVC ฝ้ายนำ = นุ่ม ใส่สบาย ดูพรีเมียม** เหมาะเสื้อโปโลแบรนด์และเสื้อยืดที่อยากได้ฟีลฝ้ายแต่ยังกันยับ กุญแจคือระบุสัดส่วนฝ้าย-โพลีให้ชัด เผื่อเรื่องงานพิมพ์และการซัก แล้วขอตัวอย่างผ้าจริงก่อนผลิต
